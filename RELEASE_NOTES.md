# Release Notes

## AAROK 1.6.5 Theme/Config Build

This release customizes Add-On Vehicle Spawner for AAROK vehicle testing.

### Added

- AAROK purple menu styling.
- AAROK title branding in the menu.
- Custom `noimage.png` preview using the AAROK logo mark.
- Installation notes.

### Changed

- Menu title changed from `Add-on spawner` to `AAROK`.
- Menu position moved slightly toward the top-left corner.
- Safer defaults for add-on testing:
  - `ListAllDLCs = false`
  - `Persistent = false`
  - `SpawnInplace = false`

### Known Limits

- The underlying ASI is still based on Add-On Vehicle Spawner 1.6.2.
- This release does not claim compiled engine-level crash/freeze fixes.
- Deeper stability changes need source access, compilation, and GTA V runtime testing.
