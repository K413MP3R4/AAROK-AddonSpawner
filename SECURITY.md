# Security Policy

## Supported Use

This package is intended only for GTA V story mode mod testing.

Do not use this package in GTA Online.

## Safety Recommendations

- Back up your GTA V folder before installing mods.
- Keep a clean unmodded GTA V copy if possible.
- Test one new vehicle pack at a time.
- Avoid enabling persistent vehicles while testing unstable add-ons.
- Keep `ListAllDLCs` disabled unless you need official DLC vehicle browsing.

## Reporting Issues

When reporting a crash or freeze, include:

- GTA V version.
- ScriptHookV version.
- Add-On Vehicle Spawner version.
- The vehicle spawn name that caused the issue.
- Any edited `.meta` files related to that vehicle.
- Whether the crash happens when opening the menu, spawning, entering, or driving the vehicle.
